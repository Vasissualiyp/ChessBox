All the board states are saved on a timeline. i.e. regular 2D chess game would have a single timeline with the states of the board changing, i.e. 1st borad is the default setup, 2nd board is e4, 3rd board is e5, etc. New board gets created on this axis with the new state whenever a move is made.
Pieces can move accross this timeline as in the 3rd dimension. Doing so creates a timeline "away" from yourself. This timeline is the 4th dimension. Pieces can move in this 4th dimension as they do via vector moves.
